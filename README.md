# Telegram Vacancy Tracker (без логина, публичные группы)

Обычный Telegram-бот. Никакого входа в личный аккаунт не требуется —
работает через открытую веб-версию публичных Telegram-групп/каналов
(`t.me/s/название`), которая доступна без авторизации.

**Ограничение:** видит только сообщения из **публичных** групп/каналов
(у которых есть короткая ссылка вида `t.me/название`, не длинная
пригласительная `t.me/+хэш`). Приватные группы без username так
получить нельзя.

## Установка

```bash
npm install
```

## Настройка

1. Токен бота: @BotFather → `/newbot`
2. `.env`:
   ```bash
   cp .env.example .env
   ```
   впиши `BOT_TOKEN`

## Запуск

```bash
npm start
```

Дальше можно раздавать друзьям username бота — каждый пишет `/start`
и настраивает себя сам, без всякого терминала.

## Команды бота

- `/start` — начало
- `/addgroup username` — добавить публичную группу/канал (можно
  несколько через запятую, можно вставлять ссылку `t.me/username`)
- `/removegroup username` — убрать группу
- `/groups` — список отслеживаемых групп
- `/keywords` — список ключевых слов
- `/add слово1, слово2` — добавить слова
- `/remove слово` — убрать слово
- `/pause` / `/resume` — вкл/выкл пересылку
- `/status` — текущий статус

## Как это работает технически

Раз в минуту бот заходит на `https://t.me/s/username` для каждой
группы, которую кто-то отслеживает, и парсит HTML этой страницы (это
публичная preview-версия, её показывает сам Telegram без всякого
входа). Новые сообщения (появившиеся с прошлой проверки) сверяются с
ключевыми словами каждого пользователя, совпадения летят в личку с
ботом.

Интервал проверки задаётся в `src/bot.ts` константой
`POLL_INTERVAL_MS` (по умолчанию 60 секунд).
